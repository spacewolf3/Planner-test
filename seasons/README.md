# The Turning Year

A phone-first daily learning spread for the current season. Each day brings one long read, one word of the day and three quick ideas, across nature, science, history, culture, folklore, food, language and the sky. A Library tab lets you browse every piece for any season.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The app. Seasons turn at the Northern Hemisphere equinoxes and solstices, and the palette and header art change with them. |
| `content.js` | All the content, about 46 pieces per season. Add to the arrays there to extend it. |

## Go deeper

Every piece ends with suggested questions and an ask box. Claude answers in place, on the reader's own Claude account, and follow-up questions work too. Select any word or phrase to ask about it. "Continue in a Claude chat" opens a new claude.ai chat about the topic.

## Where data is kept

What each reader has read, their streak and their Go deeper conversations are saved privately to their own Claude account, with the browser as a backup. Opened outside Claude, they are kept in that browser only.
